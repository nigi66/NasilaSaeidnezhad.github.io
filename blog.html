Understanding Data Categories,
Storage, and Analysis

A guide to modern data concepts, with examples.

🧩 Data Categories

1. Structured Data

Organized in rows and columns with a fixed schema.

  • Examples: Excel, MySQL, Oracle
  • Use Case: Banking transactions, sales records
Example: A table of customer purchases with columns like Customer_ID, Date, and Amount.

2. Unstructured Data

Data without a predefined structure or schema.

  • Examples: PDF, JPEG, MP3
  • Use Case: Sentiment analysis on social media or audio transcripts.

3. Semi-Structured Data

Partially organized data containing tags or markers (no fixed columns).

  • Examples: XML, JSON, NoSQL (MongoDB)
{
  "city": "London",
  "temperature": 18,
  "unit": "Celsius"
}

🏗️ Data Storage Systems

Storage Type Stores Example Tools Typical Use
Database Structured data MySQL, Oracle Transaction systems
Data Lake Structured + Raw + Unstructured data AWS S3, Azure Data Lake Big Data & ML
Data Warehouse Structured, cleaned data Snowflake, Redshift Analytics & reporting
Data Mart Subset of a data warehouse Power BI, Tableau extracts Department-level analysis
Analogy:
Database → a well-organized library.
Data Lake → a large storage room of all books.
Data Warehouse → a curated collection of best books.
Data Mart → a personal shelf for one department.

⚙️ Data Processing & Management

Data Modeling

Defines how data is structured — tables, relationships, and keys.

Data Pipeline

Series of steps that move and process data from source to destination.

ETL (Extract, Transform, Load)

Extract data → Transform → Load into warehouse. Ideal for traditional data systems.

ELT (Extract, Load, Transform)

Load raw data first, then transform inside modern cloud warehouses like BigQuery or Snowflake.

📈 Data Analysis Techniques

Descriptive Statistics (EDA)

Summarizes data using mean, median, and standard deviation to understand trends.

Inferential Statistics (Hypothesis Testing / A/B Testing)

Tests assumptions or changes, such as “Did the new design increase conversion rate?”

Time Series Analysis

Identifies trends, seasonality, and cyclical patterns — useful for forecasting sales or revenue.

🪞 Reporting and Performance Tracking

Data Visualization

Transforms insights into visual dashboards using Power BI or Tableau.

MOM, YOY, and YTD

  • MoM: Month-over-Month change
  • YoY: Year-over-Year comparison
  • YTD: Year-to-Date cumulative performance

KPI and OKR

  • KPI (Key Performance Indicator): Quantitative measure of business success (e.g., customer retention rate).
  • OKR (Objectives & Key Results): Goal-setting framework linking objectives to measurable results.
    • Objective: Improve customer satisfaction
    • Key Result: Increase NPS from 70 → 85

🧰 Example Workflow

Scenario: An e-commerce company wants to analyze customer buying trends.

  1. Collect structured sales data (MySQL) and unstructured reviews (PDF).
  2. Store all data in a Data Lake.
  3. Perform ETL to clean and load data into a Data Warehouse.
  4. Model data (customers → orders → products).
  5. Analyze trends and forecast future sales.
  6. Visualize KPIs in Power BI.
